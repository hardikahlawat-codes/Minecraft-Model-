## 📌 About

This project is a small **Minecraft-inspired 3D game/model** developed using **Python** and the **Ursina Engine**.

It was created as a learning project to explore the basics of **3D game development**, including creating a block-based world, player movement, camera controls, and interactive objects.

## 🛠️ Technologies Used

<ul>
  <li><b>Python</b></li>
  <li><b>Ursina Engine</b></li>
</ul>

## ✨ Features

<ul>
  <li>🌍 3D block-based environment</li>
  <li>🧱 Minecraft-style blocks</li>
  <li>🎮 Player movement</li>
  <li>📷 First-person camera</li>
  <li>🖱️ Interactive blocks</li>
  <li>🌱 Simple Minecraft-inspired world</li>
</ul>


## 🎯 Purpose

The main purpose of this project is to learn and experiment with **Python-based 3D game development** using the Ursina Engine.

It is a beginner-level project and is **not intended to be a complete recreation of Minecraft**.

## 📚 What I Learned

Through this project, I explored:

<ul>
  <li>Basic 3D game development</li>
  <li>Working with the Ursina Engine</li>
  <li>Creating and positioning 3D objects</li>
  <li>Player and camera controls</li>
  <li>Basic game interaction</li>
  <li>Structuring a Python game project</li>
</ul>
