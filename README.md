## 📌 About

This project is a small **Minecraft-inspired 3D game/model** developed using **Python** and the **Ursina Engine**.

It was created as a learning project to explore the basics of **3D game development**, including creating a block-based world, player movement, camera controls, and interactive objects.

## 🛠️ Technologies Used

<ul>
  <li><b>Python</b></li>
  <li><b>Ursina Engine</b></li>
</ul>

## ✨ Features

<ul>
  <li>🌍 3D block-based environment</li>
  <li>🧱 Minecraft-style blocks</li>
  <li>🎮 Player movement</li>
  <li>📷 First-person camera</li>
  <li>🖱️ Interactive blocks</li>
  <li>🌱 Simple Minecraft-inspired world</li>
</ul>

## 🎮 Game Controls

| Control                | Action                  |
| ---------------------- | ----------------------- |
| **W**                  | Move Forward            |
| **S**                  | Move Backward           |
| **A**                  | Move Left               |
| **D**                  | Move Right              |
| **Mouse**              | Look Around             |
| **Left Mouse Button**  | Place Block             |
| **Right Mouse Button** | Remove Block            |
| **1**                  | Select Grass Block      |
| **2**                  | Select Stone Block      |
| **3**                  | Select Brick Block      |
| **4**                  | Select Dirt Block       |
| **ESC**                | Open / Close Pause Menu |

### 🧱 Block Selection

The number keys allow you to select different blocks:

* **1 → Grass Block** 🌱
* **2 → Stone Block** 🪨
* **3 → Brick Block** 🧱
* **4 → Dirt Block** 🟫

After selecting a block, use the **Left Mouse Button** to place it.

Use the **Right Mouse Button** to remove an existing block.

## ⏸️ Pause Menu

Press **ESC** to open the pause menu.

The menu provides three options:

* **Resume** → Continue the game
* **Restart** → Reset the world and player position
* **Quit** → Exit the game
